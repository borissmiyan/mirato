# D-07: Устранение уязвимостей безопасности Remote Server и исправление зависаний асинхронных операций

> **Статус:** Accepted  
> **Дата:** 2026-10-30  
> **Связано с:** [D-05: Беспроводная трансляция Master ➔ Satellite](D-05-wireless-transmitter-receiver.md), [D-06: Нативный кастинг презентаций](D-06-native-deck-cast-and-airrelay-redesign.md)

---

## Контекст и Проблема
В ходе системного аудита сетевого слоя и стора презентаций были выявлены критические проблемы:
1. **Утечка секрета**: Эндпоинт `GET /airdeck/health` публично отдавал `pin` в формате открытого текста любому клиенту в локальной сети, нивелируя защиту пульта и беспроводного экрана.
2. **Отсутствие брутфорс-гарда**: 4-значный PIN на WebSocket перебирался без задержки и бана IP.
3. **Зависание промисов**: В функции `debouncedDbUpdate` (`createSlideOperationsSlice.ts`) при частых последовательных вызовах сбрасывался таймер `setTimeout`, но старые `Promise` оставались неразрешенными навечно, замораживая цепочки `await updatePresentationSlides(...)`.
4. **Квадратичная переиндексация Dexie**: `reindexVerses` использовал `offset(offset).limit(BATCH_SIZE)`, что приводило к $O(N^2)$ сканированию сотен тысяч записей.
5. **Раздутый бандл**: Чанк `vendor-react` превышал 4.1 МБ из-за огульного захвата пакетов `id.includes('react')`.

---

## Принятое решение

1. **Безопасность сетевого слоя (`RemoteServer`):**
   - Удалено поле `pin` из ответа `/airdeck/health`.
   - Внедрен IP-based rate limiter в WebSocket `AUTH`: после 5 неверных попыток накладывается блокировка на 2 минуты, исключая перебор PIN.
   - Санитизированы пути `/media/:id` и `read-file-data`: предотвращен Path Traversal через `path.basename` и проверку разрешенных расширений.

2. **Гарантия завершения промисов (`debouncedDbUpdate`):**
   - `pendingDbUpdates` переведен на хранение массива `deferreds: Array<{ resolve: () => void; reject: (err: unknown) => void }>`.
   - При срабатывании дебаунса все накопленные промисы пачки детерминированно резолвятся (или реджектятся при сбое БД).

3. **Оптимизация Dexie:**
   - Переиндексация базы стихов переведена на курсор по первичному ключу `where('id').above(lastId).limit(BATCH_SIZE)` со сложностью $O(N)$.
   - Схема версии 5 консолидирована в единое определение таблиц.

4. **Оптимизация бандла Vite:**
   - `manualChunks` разделен: чистый `vendor-react` (243 КБ вместо 4.14 МБ) и вынесенные вспомогательные библиотеки в `vendor-ui-extras`.
   - Удалены мертвые определения `GEMINI_API_KEY`.
