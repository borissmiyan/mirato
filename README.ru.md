## 🌟 О проекте Mirato

**Mirato** создано с одной главной целью: дать церкви и медиа-служению надежный, быстрый и красивый инструмент для проведения богослужений без технических сбоев.

Приложение сочетает в себе профессиональные возможности дорогих проприетарных комплексов (таких как ProPresenter), простоту интуитивного интерфейса и абсолютную независимость от облачных сервисов во время служения.

> [!TIP]
> **Mirato полностью автономно.** База текстов Библии, сборники песен, медиатека фонов и презентации хранятся локально на вашем компьютере через IndexedDB. Приложение будет работать со 100% стабильностью даже при полном отключении интернета в зале.

## ⚡ Ключевые возможности

### 📖 Мгновенный поиск Писания за 5 мс
- **Умный нечеткий парсер:** Наберите `Ин 3 16`, `Рим 8:28` или `Пс 90` — и стих уже на экране превью.
- **Параллельные переводы:** Выводите два перевода рядом (например, Синодальный + РБО или английский KJV/ESV).
- **Автоматический кегль (Auto-Fit):** Длинные стихи Писания автоматически рассчитывают размер шрифта и межстрочный интервал, гарантируя, что текст идеально уместится на экране.

### 📱 Мобильный пульт управления (Web Remote Controller)
- **Без установки приложений:** Достаточно отсканировать QR-код на любом смартфоне или планшете в локальной сети Wi-Fi.
- **Управление показом и Библией на ходу:** Оператор или пастор может переключать слайды, просматривать живое превью и находить любые места Писания прямо со смартфона с выводом на проектор.
- **Кнопки экстренного реагирования:** Включение затемнения (**Blackout**) или скрытия текста (**Clear**) в один тап из любой точки зала.
- **Защита PIN-кодом:** Настраиваемый PIN-код защищает точку управления от несанкционированного доступа.

### 🎵 Церковные песенники и сборники псалмов
- **Встроенная база сборников:** Быстрый поиск песен по номеру, названию или фрагменту текста.
- **Структурированные куплеты:** Автоматическое разделение на куплеты, припевы и бриджи с быстрым переходом в один клик.
- **Готовые темы оформления:** Эстетичные шаблоны стилей, созданные специально для текстов прославления.

### 📐 Векторный холст и редактор слайдов нового поколения
- **Figma-подобный векторный движок:** Свободное размещение текстовых блоков, медиа, геометрических фигур и шейпов.
- **Smart Guides & Magnetic Snapping:** Умные направляющие выравнивания и привязка к центру слайда и границам других элементов.
- **Мгновенный выбор разрешения:** Переключение соотношения сторон (16:9, 16:10, 4:3, 9:16) через оверлей-портал поверх всех панелей.

### 🖥️ Независимый режим докладчика и два дисплея
- **Изолированный процесс проектора:** Окно второго экрана работает независимо — курсор оператора свободен, можно готовить слайды прямо во время показа.
- **Редактирование на лету:** Исправление опечаток или добавление новых слайдов происходит прямо во время богослужения без остановки проекции.

### 🚨 Панические клавиши оператора (Panic Keys)
- В непредвиденной ситуации на сцене не нужно судорожно искать мышь:
  - `F1` — **Blackout** (мгновенное мягкое затемнение проектора в черный).
  - `F2` — **Clear Text** (мгновенно убрать текст, оставив красивое фоновое видео/заставку).
  - `Esc` — возврат к слайду или сброс оверлеев.

| **Суфлер для сцены (AirDeck)** | Встроенный беспроводной суфлер по QR-коду | Отсутствует | Требует отдельное платное iOS-приложение |

| **Панические клавиши (F1/F2)** | Аппаратные хоткеи затемнения экрана | Только клавиша `B` (черный экран) | Настраиваемые |
| **Стоимость лицензии** | **Бесплатно и Open Source (MIT)** | Подписка Microsoft 365 | От \$399 + ежегодные платные обновления |

## 🍎 Важная инструкция по запуску на macOS (Команда `xattr`)

Так как Mirato распространяется свободно и с открытым исходным кодом без платной ежегодной подписки разработчика Apple, встроенная система безопасности **Apple Gatekeeper** при первом открытии может показать сообщение:

> *«Программа "Mirato" повреждена и её невозможно открыть. Вам следует переместить её в Корзину»*

### Разблокировка занимает 10 секунд:
1. Перетащите **Mirato.app** из смонтированного диска в папку **«Программы»** (`/Applications`).
2. Откройте стандартный **Терминал** (Terminal) через Spotlight (`Cmd + Пробел` → введите *Терминал*).
3. Вставьте и выполните следующую команду:

```bash
xattr -cr /Applications/Mirato.app
```

*(Если система запросит права администратора, выполните: `sudo xattr -rd com.apple.quarantine /Applications/Mirato.app`)*

4. Запустите Mirato снова. Приложение откроется мгновенно и больше никогда не будет запрашивать подтверждений!

> [!NOTE]
> Текстовый файл с этой командой также включен непосредственно в смонтированный DMG-образ (`Команда_для_Терминала.txt`).

## 🛠️ Стек технологий

- **Ядро десктопа:** [Electron](https://www.electronjs.org/) с раздельной многооконной архитектурой контроллера и проектора.
- **Пользовательский интерфейс:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/) + [Tailwind CSS v4](https://tailwindcss.com/).
- **Управление состоянием:** [Jotai](https://jotai.org/) (атомарный UI-стейт) + [Zustand](https://zustand-demo.pmnd.rs/) (презентационные срезы).
- **Хранилище данных:** [Dexie.js](https://dexie.org/) (IndexedDB) с полной автономностью.
- **Связь и пульт:** Встроенный HTTP и WebSocket сервер для мгновенной синхронизации Web Remote и сценического суфлера.
- **Медиа-движок:** Встроенный [FFmpeg WebAssembly](https://ffmpegwasm.netlify.app/) для фоновой генерации превью и кэширования видео.

## 👨‍💻 Разработка и сборка из исходников

```bash
# 1. Клонирование репозитория
git clone https://github.com/borissmiyan/mirato.git
cd mirato

# 2. Установка зависимостей
npm install

# 3. Запуск в режиме разработки
npm run dev

# 4. Проверка качества и тестов (588 тестов)
npm run check:design
npm run check:hygiene
npm run check:esm
npx vitest run

# 5. Сборка продакшн-пакетов
npm run build:mac-modern   # macOS Apple Silicon + Intel DMG
npm run build:win          # Windows Installer
npm run build:linux        # Linux AppImage
```
