## 🌟 О проекте Mirato

**Mirato** создано с одной главной целью: дать церкви и медиа-служению надежный, быстрый и красивый инструмент для проведения богослужений без технических сбоев.

Приложение сочетает в себе профессиональные возможности дорогих проприетарных комплексов (таких как ProPresenter), простоту интуитивного интерфейса и абсолютную независимость от облачных сервисов во время служения.

> [!TIP]
> **Mirato полностью автономно.** База текстов Библии, сборники песен, медиатека фонов и презентации хранятся локально на вашем компьютере через IndexedDB. Приложение работает со 100% стабильностью даже при полном отсутствии интернета в зале.

## ⚡ Ключевые возможности

### 📖 Мгновенный поиск Писания за 5 мс
- **Умный нечеткий парсер:** Наберите `Ин 3 16`, `Рим 8:28` или `Пс 90` — и стих уже на экране превью.
- **Параллельные переводы:** Выводите два перевода рядом (например, Синодальный + РБО или английский KJV/ESV).
- **Автоматический кегль (Auto-Fit):** Длинные стихи Писания автоматически рассчитывают размер шрифта и межстрочный интервал, гарантируя, что текст идеально уместится на экране.

### 📱 Мобильный веб-пульт (Web Remote Controller)
- **Без установки сторонних приложений:** Достаточно отсканировать QR-код на любом смартфоне или планшете в локальной сети Wi-Fi.
- **Управление показом и Библией с телефона:** Оператор или пастор может переключать слайды, просматривать живое превью и находить любые места Писания прямо со смартфона с мгновенным выводом на проектор.
- **Оверлеи эфира:** Включение затемнения (**Blackout**), заливки белым (**Whiteout**) или вывод логотипа (**Logo**) с мобильного экрана.
- **Защита PIN-кодом:** Настраиваемый PIN-код защищает точку управления от несанкционированного доступа.

### 🎵 Церковные песенники и сборники псалмов
- **Встроенная база сборников:** Быстрый поиск песен по номеру, названию или фрагменту текста.
- **Структурированные куплеты:** Автоматическое разделение на куплеты, припевы и бриджи с быстрым переходом в один клик.
- **Стили оформления:** Эстетичные шаблоны, созданные специально для текстов прославления.

### 📐 Векторный холст и редактор слайдов
- **Векторный движок на базе холста:** Свободное размещение текстовых блоков, медиа, геометрических фигур (прямоугольники, круги, линии) и векторного пера.
- **Smart Guides & Magnetic Snapping:** Умные направляющие выравнивания и привязка к центру слайда и границам соседних элементов.
- **Мгновенный выбор соотношения сторон:** Переключение пропорций (16:9, 16:10, 4:3, 9:16) через оверлей-портал поверх всех панелей.

### 🖥️ Независимый режим докладчика и два дисплея
- **Изолированный процесс проектора:** Окно второго экрана работает независимо — курсор оператора никогда не блокируется, можно готовить слайды прямо во время показа.
- **Редактирование на лету:** Исправление опечаток или добавление новых слайдов происходит прямо во время богослужения без остановки проекции.

### 🚨 Клавиши оверлеев эфира (Live Overrides)
- Клавиши прямого действия без поиска мыши:
  - `B` — **Blackout** (плавное затемнение проектора в черный).
  - `W` — **Whiteout** (заливка проектора чистым белым цветом).
  - `L` — **Logo** (мгновенный вывод церковного логотипа на экран).
  - `Esc` — закрыть окно проектора или сбросить выбор.

## 📊 Сравнение: Mirato vs PowerPoint vs ProPresenter

| Возможность | 👑 Mirato 2.3 | 📄 MS PowerPoint | 🎥 ProPresenter |
| :--- | :---: | :---: | :---: |
| **Режим докладчика и мышь** | Полная свобода курсора, оператор работает во время показа | Крадет фокус мыши, легко случайно свернуть показ | Сложный многооконный интерфейс, высокая нагрузка на GPU |
| **Редактирование на лету** | Мгновенно во время служения без выхода из показа | Невозможно без остановки презентации | Возможно, но требует открытия громоздкого редактора |
| **Поиск Библии** | 5 мс (Ин 3:16), параллельные переводы, авто-верстка | Отсутствует (только ручной копипаст из браузера) | Доступен за дополнительную плату за модули |
| **Мобильный пульт (Web Remote)** | Встроенный веб-пульт по QR-коду/Wi-Fi (с поиском Библии и превью) | Базовый кликер или приложение с подпиской Office 365 | Требует отдельного приложения ProRemote и ручной настройки портов |
| **Экран сцены (Stage Display)** | Встроенный сценический монитор (часы, таймер, слайды) | Отсутствует | Требует отдельный модуль настройки экранов |
| **Церковные песенники** | Встроенная база сборников с быстрым поиском по номеру | Отсутствуют (каждая песня верстается вручную) | Базовый текстовый импорт / платная подписка CCLI |
| **Оверлеи эфира (Blackout/Logo)** | Хоткеи прямого действия (`B`, `W`, `L`) | Только клавиша `B` (черный экран) | Настраиваемые |
| **Стоимость лицензии** | **100% Бесплатно и Open Source (MIT)** | Подписка Microsoft 365 | От \$399 + ежегодные платные обновления |

## 🍎 Важная инструкция по запуску на macOS (Команда `xattr`)

Так как Mirato распространяется свободно и с открытым исходным кодом без платной ежегодной подписки разработчика Apple ($99/год), встроенная система безопасности **Apple Gatekeeper** при первом открытии может показать сообщение:

> *«Программа "Mirato" повреждена и её невозможно открыть. Вам следует переместить её в Корзину»*

### Разблокировка занимает 10 секунд:
1. Перетащите **Mirato.app** из смонтированного диска в папку **«Программы»** (`/Applications`).
2. Откройте стандартный **Терминал** (Terminal) через Spotlight (`Cmd + Пробел` → введите *Терминал*).
3. Вставьте и выполните следующую команду:

```bash
xattr -cr /Applications/Mirato.app
```

*(Если система запросит права администратора, выполните: `sudo xattr -rd com.apple.quarantine /Applications/Mirato.app`)*

4. Запустите Mirato снова. Приложение откроется мгновенно и больше никогда не будет запрашивать подтверждений!

> [!NOTE]
> Текстовый файл с этой командой также включен непосредственно в смонтированный DMG-образ (`Команда_для_Терминала.txt`).

## 🛠️ Стек технологий

- **Десктопная среда:** [Electron](https://www.electronjs.org/) с изоляцией процессов контроллера и проектора.
- **Интерфейс:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/) + [Tailwind CSS v4](https://tailwindcss.com/).
- **Состояние:** [Jotai](https://jotai.org/) (атомарный UI-стейт) + [Zustand](https://zustand-demo.pmnd.rs/) (презентационные срезы).
- **База данных:** [Dexie.js](https://dexie.org/) (IndexedDB) с офлайн-хранением.
- **Сетевой сервер:** Встроенный HTTP и WebSocket сервер для Web Remote и сценического экрана.
- **Медиа-ядро:** [FFmpeg WebAssembly](https://ffmpegwasm.netlify.app/) для фоновой обработки превью.

## 👨‍💻 Разработка и сборка из исходников

```bash
# 1. Клонирование репозитория
git clone https://github.com/borissmiyan/mirato.git
cd mirato

# 2. Установка зависимостей
npm install

# 3. Запуск в режиме разработки
npm run dev

# 4. Проверка качества и тестов (588 тестов)
npm run check:design
npm run check:hygiene
npm run check:esm
npx vitest run

# 5. Сборка продакшн-пакетов
npm run build:mac-modern   # macOS Apple Silicon + Intel DMG
npm run build:win          # Windows Installer
npm run build:linux        # Linux AppImage
```
