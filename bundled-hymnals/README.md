# Bundled Hymnals

This directory contains hymnal packages (`.ektp` files) that are bundled directly into the application installer and automatically copied to the user's local `Hymnals` directory on startup.

## Structure
Hymnals are organized by language to make importing easier and to enable bilingual support:
- `ru/` - Russian hymnals
- `en/` - English hymnals
- `de/` - German hymnals

For instructions on how to create and bundle new hymnals, see `docs/HOW_TO_ADD_HYMNALS.md`.
