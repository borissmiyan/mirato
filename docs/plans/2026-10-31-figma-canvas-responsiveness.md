# Редактор слайдов: Figma-Grade отзывчивость и Smart Guides (Спринт 1) — Implementation Plan

> **Статус:** [APPROVED]  
> **Стек:** React 19, TypeScript, Tailwind CSS v4, Jotai / Zustand, Vitest  
> **Связанные ADR:** ADR D-04 (лимит строк), ADR D-13 (ESM & Runtime Hygiene)  
> **Оценка Diff Budget:** ~240 строк кода, 6 файлов (Лимит харнесса: 450 строк / 10 файлов)  

---

### Цель и Архитектура
* **Цель:** Превратить работу в холсте редактора слайдов в плавный, высокоточный процесс уровня Figma: устранить лаги масштабирования, разделить панорамирование и зум, добавить панорамирование по пробелу и магнитные направляющие (Smart Guides) к центру и границам.
* **Архитектурный подход:**
  1. Вынести алгоритм вычисления магнитных прилипаний (центр 50%, безопасные поля 5%/95%, центры и границы соседних элементов) в чистые функции `canvasMath.ts` с покрытием юнит-тестами TDD.
  2. Добавить легковесный компонент визуализации направляющих `CanvasSmartGuides.tsx` (1px акцентные линии с индикатором совпадения).
  3. Обновить `SlideDisplay.tsx`: обычный скролл/свайп выполняет панорамирование (Pan), а зум срабатывает только при зажатом `Cmd/Ctrl` или тачпад-жесте pinch; добавить режим Spacebar-панорамирования (зажал `Space` — курсор `grab`, кликнул-потянул).
  4. В `LogicalCanvas.tsx` оптимизировать transition-поведение, устранив 500ms задержку при изменении геометрии холста.

---

### Границы задачи (Scope Lock & Non-Goals)
* ✅ **Входит в скоуп (Спринт 1):**
  - Разделение скролла: обычный свайп/колесо = Pan, `Cmd/Ctrl` + скролл / pinch = Zoom к курсору.
  - Панорамирование по пробелу (`Space + Drag`) с переключением курсора `grab` / `grabbing` и сохранением предыдущего инструмента.
  - Горячие клавиши масштаба (`Cmd+0` — Fit, `Cmd+1` — 100%).
  - Устранение лага ресайза в `LogicalCanvas.tsx`.
  - Магнитное прилипание (Snap to Center X=50%, Y=50%, Snap to Safe Edges) с порогом ~1.5%.
  - Отображение Smart Guides (акцентные линии) в момент совпадения осей.
  - Полноценные юнит-тесты на математику снаппинга в `canvasMath.test.ts`.
* 🛑 **НЕ входит (Спринт 2 / Non-Goals):**
  - Рефакторинг инспектора свойств (`ItemProperties.tsx`, `TypographySection.tsx`).
  - Горизонтальный скраббинг `ScrubbableInput` (запланирован в Спринте 2).
  - Модификация сохранения слайдов в БД (Dexie/Supabase) — данные слайдов не меняют формат.

## 🕵️ Adversarial Critic Audit Gate

- [x] **Фильтр 1 (Offline & State Integrity):** Изменения затрагивают только визуальный слой холста и transient UI-координаты во время драга. Схема данных и персистентность не меняются.
- [x] **Фильтр 2 (Physical & Mathematical Invariants):** Математика снаппинга учитывает нормализованные координаты (0–100%) и имеет защиту от деления на ноль и выхода за границы [0, 100].
- [x] **Фильтр 3 (Diff Budget < 450 lines / 10 files):** Планируемый дифф: ~240 строк кода, 6 файлов.
- [x] **Фильтр 4 (Type Safety & noUncheckedIndexedAccess):** Строгие интерфейсы для `ISnapGuide`, `ISnapResult`, явные проверки `undefined` для массивов элементов.
- [x] **Фильтр 5 (Race Conditions & Edge Cases):** `Space` игнорируется, если фокус находится в текстовом поле или в режиме `InlineTextEditor` (чтобы пробел печатался в тексте).

- [x] **Фильтр 7 (UI & Localization):** Нет сырых эмодзи в JSX. Добавляются локализованные подсказки для новых шорткатов.

## 📐 Пошаговый план реализации (TDD-микрошаги)

### Шаг 1 (TDD Red): Тесты для математики магнитного прилипания и умных направляющих
* Создать `src/core/utils/canvasMath.test.ts`.
* Покрыть тестами сценарии:
  1. Прилипание к центру слайда по X (50%) при поднесении к 49%..51%.
  2. Прилипание к центру слайда по Y (50%).
  3. Прилипание к безопасным границам (5%, 95%).
  4. Прилипание к границам соседних объектов.
  5. Отключение снаппинга при превышении порога чувствительности (threshold).
* *Команда:* `npx vitest run src/core/utils/canvasMath.test.ts` (ожидаем RED).

### Шаг 2 (TDD Green): Реализация чистого алгоритма `calculateSmartSnap` в `canvasMath.ts`
* Реализовать функции:
  - `calculateSmartSnap(x, y, w, h, otherItems, threshold)`
  - Возврат `{ snappedX, snappedY, guides: ISnapGuide[] }`
* *Команда:* `npx vitest run src/core/utils/canvasMath.test.ts` (ожидаем GREEN).

### Шаг 3: Компонент `CanvasSmartGuides.tsx`
* Создать легковесный оверлей `CanvasSmartGuides.tsx`, рендерящий направляющие линии (горизонтальные и вертикальные) через координаты в процентах с плавной анимацией появления.

### Шаг 4: Интеграция Smart Guides в `useCanvasInteraction.ts` и `SlideCanvas.tsx`
* В `useCanvasInteraction.ts` при типе драга `move` применять `calculateSmartSnap`.
* Если зажат `Cmd` / `Ctrl`, временно отключать снаппинг (Figma-поведение: свободное перетаскивание).
* Экспортировать `activeGuides` и передавать в `CanvasSmartGuides`.

### Шаг 5: Figma-навигация в `SlideDisplay.tsx` и `LogicalCanvas.tsx`
* В `SlideDisplay.tsx`:
  - Разделить скролл: если нет `ctrlKey` / `metaKey`, изменять `offset.x -= e.deltaX` и `offset.y -= e.deltaY` (Pan).
  - Если зажат `ctrlKey` / `metaKey` (или pinch), вычислять зум к позиции мыши.
  - Добавить глобальный слушатель `Space` (когда не в input/textarea): переключение режима `isSpacePanning`, курсор `grab`/`grabbing`.
  - Добавить шорткаты `Cmd+0` (сброс к Fit) и `Cmd+1` (100%).
* В `LogicalCanvas.tsx`:
  - Убрать постоянную задержку `duration-500` при активных трансформациях или масштабировании.
