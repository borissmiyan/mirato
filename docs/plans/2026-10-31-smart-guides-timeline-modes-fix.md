# Комплексная доработка редактора слайдов, таймлайна и смарт-гайдов — Implementation Plan

> **Статус:** [APPROVED]  
> **Стек:** React 19, TypeScript, Tailwind CSS v4, Jotai / Zustand, Vitest  
> **Связанные ADR:** ADR D-04 (500 строк лимит), ADR D-13 (ESM & Runtime Hygiene)  
> **Оценка Diff Budget:** ~380 строк кода, 8 файлов (Лимит харнесса: 450 строк / 10 файлов)  

---

### Цель и Архитектура
* **Цель:**
  1. Исправить математику и поведение направляющих (Smart Guides): поддержать полное прилипание всех 3 точек прямоугольника (left/center/right и top/center/bottom) ко всем осям (0%, 5%, 50%, 95%, 100% и другим объектам).
  2. Реализовать высококонтрастное оформление направляющих в палитре приложения (amber, blue, rose, slate) с двойной защитой от слияния с черным/белым фоном.
  3. Устранить 3–4 сек задержку добавления элементов: мгновенное синхронное обновление стора Zustand и оптимистичный рендеринг без ожидания записи в БД.
  4. Настроить контекстное разделение шорткатов: Пробел на холсте = панорамирование, на таймлайне/вне холста = управление воспроизведением live media; документировать шорткаты в настройках.
  5. Реализовать 3 состояния таймлайна (hidden, compact, expanded) с кнопкой переключения в правом нижнем углу и плавной адаптацией вьюпорта слайда.

---

### Границы задачи (Scope Lock & Non-Goals)
* ✅ **Входит в скоуп:**
  - Полный перерасчет матрицы прилипания в `canvasMath.ts` + тесты `canvasMath.test.ts`.
  - Высококонтрастная стилизация направляющих в `CanvasSmartGuides.tsx`.
  - Синхронное добавление элементов в `createCanvasSlice.ts` (0ms lag).
  - Контекстный фильтр горячих клавиш в `useGlobalShortcuts.ts` и `SlideDisplay.tsx`.
  - Добавление шорткатов холста в `ShortcutsSettings.tsx`.
  - Состояние `timelineModeAtom` ('hidden' | 'compact' | 'expanded') и переключатель `TimelineModeToggle.tsx`.
  - Поддержка компактного режима (скрытие дорожки аудио и Live) в `SlideTimeline.tsx`.
  - Адаптация отступа `viewportPadding.bottom` в `SlideDisplay.tsx` для автоматического увеличения холста в компактном и скрытом режимах.

## 📐 Пошаговый план реализации

### Шаг 1: Матричный алгоритм Smart Guides в `canvasMath.ts` и тесты в `canvasMath.test.ts`
* Расширить цели для вертикальной оси (X):
  - Слайд: 0% (левый край), 5% (safe-left), 50% (центр), 95% (safe-right), 100% (правый край).
  - Соседние объекты: `o.x`, `o.x + o.w / 2`, `o.x + o.w`.
* Для каждого целевого $X$ проверять все 3 точки перемещаемого объекта: $x$, $x + w / 2$, $x + w$.
* Аналогично для горизонтальной оси (Y): 0%, 5%, 50%, 95%, 100% и точки $y$, $y + h / 2$, $y + h$.
* Запуск `npx vitest run src/core/utils/canvasMath.test.ts` (100% green).

### Шаг 2: Высококонтрастное оформление в `CanvasSmartGuides.tsx`
* Цветовая дифференциация:
  - Центр (50%): Amber-500 (`#f59e0b`).
  - Safe-margin (5%, 95%): Sky-400 (`#38bdf8`).
  - Границы слайда (0%, 100%): Slate-400 (`#94a3b8`).
  - Соседние объекты: Rose-500 (`#f43f5e`).
* Двойная обводка для абсолютного контраста на черном и белом фоне:
  `shadow-[0_0_0_1px_rgba(0,0,0,0.8),0_0_6px_currentColor]`.

### Шаг 3: Мгновенное (0ms) добавление элементов на холст в `createCanvasSlice.ts`
* Оптимистичное обновление Zustand store `set(...)` ПЕРВЫМ синхронным шагом.
* Фоновое асинхронное сохранение снимка в историю и БД без блокировки рендера.

### Шаг 4: Контекстные шорткаты и отображение в настройках
* В `useGlobalShortcuts.ts`: Пробел для live media блокируется, если `isPreviewHovered === true`.
* В `ShortcutsSettings.tsx`: добавить пункты шорткатов панорамирования по пробелу, нуджинга стрелками, масштаба 100%.
* В файлах локализации `ru/settings.ts`, `en/settings.ts`, `de/settings.ts` добавить недостающие ключи.

### Шаг 5: 3 состояния таймлайна (hidden, compact, expanded) и кнопка переключения
* Добавить атом `timelineModeAtom` в `src/core/store/uiAtoms.ts`.
* Добавить компонент `TimelineModeToggle.tsx` (в правом нижнем углу, позиционируемый на высоте тулбара при открытом таймлайне и в самом низу при закрытом).
* Поддержать в `SlideTimeline.tsx` скрытие дорожки аудио и лайва в режиме `compact`, а также `hidden`.
* Обновить расчет `viewportPadding.bottom` в `SlideDisplay.tsx`.
