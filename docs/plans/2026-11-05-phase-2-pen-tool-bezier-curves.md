### Цель и Архитектура
* **Цель:** Предоставить пользователю профессиональный Figma-grade векторный редактор: вход в Vector Edit Mode по двойному клику или клавише `Enter` на любой фигуре или линии, отображение узлов контура и направляющих Безье (`handleIn`, `handleOut`), инструмент «Перо» (`P`) для создания произвольных гладких или угловых кривых, и бесшовное закрытие контуров с применением заливок и обводок.
* **Архитектурный подход:**
  1. **Модель данных:** Добавление типа `IVectorPoint`, `IVectorNode`, `ICanvasItemPath` и элемента `'path'` в `ICanvasItem`.
  2. **Геометрическое ядро (`vectorGeometry.ts`):** Конвертация набора узлов с кубическими кривыми Безье в стандартизированный SVG-путь `M ... C ... Z`, конвертация примитивов (прямоугольник, треугольник, ромб, линия) в начальную векторную сеть.
  3. **Интерактивный оверлей (`CanvasVectorEditor.tsx`):** Отображение узлов (квадраты/круги) и усиков Безье с live RAF-перетаскиванием, переключение острого/гладкого узла по двойному клику, `Alt` для разрыва симметрии усиков, кнопка «Готово» / `Esc` / `Enter` для выхода.
  4. **Инструмент Перо (`P`):** Активация на тулбаре, клик — создание вершины, клик с драгом — вытягивание усиков кривой, клик на начальную точку — замыкание контура.

### Границы задачи (Scope Lock & Non-Goals)
* ✅ **Входит в скоуп (Фаза 2):**
  * Тип `path` в `ICanvasItem` с узлами и флагом `isClosed`.
  * Математика кубических кривых Безье в `vectorGeometry.ts` и юнит-тесты.
  * Vector Edit Mode (двойной клик на фигуру / Enter / кнопка «Готово»).
  * Усики Безье с зеркальной симметрией и разрывом по `Alt`.
  * Инструмент «Перо» (`P`) на тулбаре.
  * Рендеринг `path` с заливками и обводками в `PathRenderer.tsx` и `CanvasItemView.tsx`.
* 🛑 **НЕ входит (Non-Goals для Фазы 2 — перенесено в Фазу 3):**
  * Контейнерные группы `Cmd+G` / `Cmd+Shift+G` (Фаза 3).
  * Режим масок `isMask: true` (Фаза 3).

## 🕵️ Adversarial Critic Audit Gate (7 Фильтров)

- [x] **Фильтр 1 (Offline & Dexie Integrity):** Все изменения `path` сохраняются через существующий атомарный пайплайн `updateCanvasItem` в Zustand + автобэкап Dexie/JSON.
- [x] **Фильтр 2 (Physical & Mathematical Invariants):** Защита от деления на 0 при вычислении углов и длин касательных Безье. Гарантирован минимальный габарит элемента (0.5% ширины/высоты).
- [x] **Фильтр 3 (Diff Budget < 450 строк / 10 файлов):** Оценка диффа: ~380 строк в 9 файлах. Все файлы строго до 300 строк.
- [x] **Фильтр 4 (Type Safety & noUncheckedIndexedAccess):** Строгие интерфейсы `IVectorNode` и `IVectorPoint`, fallback при отсутствии `handleIn`/`handleOut`.
- [x] **Фильтр 5 (Race Conditions & Double-Clicks):** Перетаскивание узлов использует `PointerCapture` и RAF-троттлинг (120 FPS). Завершение редактирования происходит чисто без висячих листнеров.
- [x] **Фильтр 6 (Anti-Test Tampering):** Не трогаем существующие тесты. Новые тесты покрывают генерацию SVG кубических кривых Безье и конвертацию фигур.
- [x] **Фильтр 7 (UI & Localization):** Векторная иконка `Pen` из `lucide-react`. Все строки интерфейса локализованы (`ru`, `en`, `de`).
