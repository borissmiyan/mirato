# Mirato. Church Edition v2.4.4

Релиз, полностью посвящённый скорости работы, плавности интерфейса и стабильности сборников гимнов на Windows, macOS (Apple Silicon / Intel) и Linux.

## Что нового и ускорено

- **Мгновенный запуск и поиск гимнов (~20 мс вместо 3–5 с):** индекс поиска по всем 5 293 встроенным и пользовательским гимнам теперь сохраняется одним компактным снимком в локальной базе и не пересобирается заново при каждом открытии приложения.
- **Плавная работа редактора и таймлайна без фризов:** устранены фоновые полные сканы таблицы гимнов (~100–200 МБ JSON) при редактировании слайдов, открытии библиотеки GraceLib, автобэкапе, создании презентаций и работе со списком аудио.
- **Стабильный HymnPicker при смене тем:** переведена инвалидация индекса на режим *stale-while-revalidate* — список гимнов больше не пропадает на несколько секунд при выборе темы или фоновой синхронизации сборников.
- **Улучшенное распознавание аудиопакетов (минусовок и плюсовок) на macOS Apple Silicon:** добавлен резервный поиск аудиопакетов по нормализованному названию сборника, чтобы кнопки загрузки «Минусовки / Плюсовки» отображались стабильно для всех сборников.
- **Оптимизация рендера таймлайна и медиапула:** мемоизация карточек слайдов (`SlideTile`), стабильная мемоизация списка медиапула и отключение фонового 500 мс опроса аудио в тишине.

## Установка на macOS
Внутри каждого `.dmg` вложен файл **`Команда_для_Терминала.txt`** с короткой инструкцией для первого запуска на macOS.
